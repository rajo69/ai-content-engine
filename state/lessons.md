# Cross-run lessons (injected into every future run)

Distilled process lessons — not paper-specific facts. Keep under ~30 bullets; merge or drop the least valuable when adding would exceed that.

- Reproduction: before adopting a model as the "weak" endpoint of a competence axis, screen it for degeneracy — check its ICL accuracy clears the majority-class baseline and that it isn't one-class-dominant (a `frac_pred_pos`-style diagnostic). This run's P3 failed because GPT-2-small was *broken* at SST-2 ICL (below the 54% majority baseline), not merely weak, so the axis spanned broken→good instead of weak→good and the core experiment was unreachable by construction.
- When compute is CPU/box-bound, prioritize arithmetic on the paper's *own* published tables (banked, GPU-free, reproducible) over a token reimplementation. This run's strongest, most-defensible finding (the omitted-ICL baseline + monotone gradient) came entirely from re-aggregating Appendix B; the laptop reproduction only added a single sign-check at the small end.
- Never treat `ingest/references.json` as complete or authoritative: this run's primary baseline (LoRA) failed to resolve and was missing, and a mis-linked entry ("The Context", about Ukrainian economics) was flagged `isInfluential`. Verify the paper's main baseline resolved, and topic-check any `isInfluential` abstract before trusting it.
- When transcribing pre-registered predictions into a separate `predictions.json`, key each to the exact calibration the source used (e.g. the specific dataset column), not a pooled average — this run's P1/P2 transcription silently switched to the 6-dataset pooled basis and manufactured scoring conflicts against the analysis it claimed to copy.
- Adversarial review: content that survives fact-checking cleanly can still hide *scoping* errors — a correct number attached to the wrong basis (e.g. an all-dataset average labeled as a "security-task" result) or a variance qualifier ("outside noise") that's true for one arm but silently applied to both. Hunt for mismatched bases and misapplied qualifiers, not just wrong digits.
